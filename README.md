# 🛒 Bodega JIVA - Catálogo Online

¡Bienvenido al repositorio oficial de la tienda online de **Bodega JIVA**! Esta es una aplicación web moderna, rápida y con un diseño premium diseñada para ofrecer la mejor experiencia de compra a nuestros clientes.

## ✨ Características Principales
- 🎨 **Diseño Premium:** Estética moderna con colores Azul Real y Naranja Vibrante.
- 📱 **Mobile-First:** Optimizado perfectamente para dispositivos móviles.
- ❄️ **Efectos Visuales:** Fondo animado de nieve y transiciones suaves de emojis.
- 🛍️ **Catálogo Dinámico:** Filtros por categorías y gestión de promociones especiales.
- 💬 **Pedidos por WhatsApp:** Integración directa para finalizar pedidos vía chat.
- 💳 **Múltiples Métodos de Pago:** Soporte para Yape, Plin, Transferencia y Efectivo.

## 🚀 Tecnologías Utilizadas
- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (Efectos de vidrio, gradientes y animaciones personalizadas)
- **Lucide React** (Iconografía moderna)

## 🛠️ Instalación y Uso Local

1. Clona el repositorio:
   ```bash
   git clone <url-del-repo>
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## 📦 Despliegue
Este proyecto está listo para ser desplegado como un sitio estático en plataformas como **Render**, **Vercel** o **Netlify**.

Comando de construcción:
```bash
npm run build
```
